# 我们的恋爱博物馆

王宇超与卓如怡的粉色手账。网页由 GitHub Pages 托管，数据和照片由独立的 Supabase 项目保存。

浏览器通过 Netlify Free 连接服务访问云端文字与私有照片，以免需要直接连接 Supabase 域名。连接服务的源代码在 `museum-relay`，不保存数据库或邀请凭证。

使用专属邀请链接进入；它会在浏览器本机保存进入凭证。页面底部“双人邀请”可复制完整链接，发送给对方或用于换手机。邀请链接等同进入凭证，请只发给彼此，不要提交到公开仓库。

支持回忆新增/编辑/删除、照片相册、时光轴、相恋天数、纪念日、书信、完整备份导入和导出。页面在前台且未编辑时约每 10 秒检查云端更新，切回页面时也会同步。编辑对话框打开时等待编辑结束后再同步，避免干扰输入。

公开代码只包含界面和 API 地址，不包含邀请钥匙、后台管理密钥、私人照片或恋爱记录。数据表启用 RLS 并拒绝公开客户端读写；云端接口校验高强度邀请凭证后才操作当前博物馆的数据，照片存储桶为私有。

完整备份包含照片、回忆和专属邀请链接，应妥善保存。清除浏览器数据或换手机后，可重新使用专属链接进入，不会删除云端收藏。
